## 🧠 TradingAgents 风格多智能体投决会 (AI Agent Copilot)

基于 **TradingAgents** 架构与 **DeepSeek-V3** 大模型，打造华尔街对冲基金级的投决会决策副驾驶：

1. **四大专家角色联合辩论**：
   - **宏观与地缘政治分析师**：跟踪中东战局、国际原油破百风险、二次通胀冲击与美联储利率预期；
   - **量化技术派分析师**：基于 Moomoo 美股 ETF 行情（MA50/MA200 关键线位、年化已实现波动率）定量体检；
   - **多空博弈辩论席**：激进多头与严谨空头激烈碰撞，揭示潜在收益与回撤敞口；
   - **CIO 与风控总监**：综合辩论意见，给出明确的首次建仓比例（如 30% 分批）与止损硬指标。
2. **量化订单二次风控审查与裁决**：
   - 策略产生的每笔调仓清单（标的、买卖方向、预估金额、目标权重）由投决会**一对一审查**；
   - 裁决状态：`🟢 APPROVED (批准执行)`、`🟡 TRIMMED (建议缩减)`、`🔴 REJECTED (建议暂缓)`、`🟣 HEDGED (建议对冲)`；
   - **严格杜绝碎股（小数股）**：全流程采用**纯整数股**规则，支持富途/Moomoo限价单直接下单。
3. **决策历史追溯与研判连贯性保证**：
   - 每次投决会研判均按时间戳自动归档（`data/ai_analysis/history/`），支持下拉历史回溯；
   - 每轮运行输入上期结论，生成稳定性评注（`stability_comment`），严防日内无实质变化反复摇摆。

## 💰 策略规模控制与资金隔离 (Capital Budget & Isolation)

很多投资者不希望把账户全部资金一次性投入量化策略。系统提供了完整的资金预算与资产隔离保护机制：

1. **三大资金规模模式**：
   - **全量资产模式 (Full NAV)**：以账户总资产为基准分配权重；
   - **固定金额模式 (Custom Amount)**：设置特定运行规模（如 `$3,000` 或 `$10,000` 试水跑策略）；
   - **比例分配模式 (Percent)**：按总资产的一定比例（如 `50%`）作为策略运作资金；
2. **非策略自主持仓物理隔离**：
   - 自动识别非策略标的（如长期持有的底仓个股或非池内资产），**绝不强制报单平仓**，闲置资金作为受保护资产独立核算；
3. **卫星持仓阶梯化分配**：
   - 支持领涨标的等权（`EQUAL` 50%/50%）或动量阶梯分配（`TIERED_60_40`、`TIERED_65_35`），让龙头享受更多权重溢价。

## 🔒 实盘安全与风控机制（Hard Safety Lock）

针对实盘资金对接，系统设计了严密的安全准则：
1. **物理安全锁拦截**：
   - 当连接到 Moomoo OpenD 实盘账户（`TrdEnv.REAL`）时，系统底层强制激活拦截锁（`RealTradeSafetyError`），**物理禁止任何代码直接向券商接口发出真实下单指令**；
2. **币种自动校准**：
   - 自动适配富途/Moomoo 多币种账户架构，强制指定 `currency='USD'` 并读取底层 `usd_assets` / `us_cash`，消除港币默认结算导致的资金失真；
3. **差异化调仓与换仓解释**：
   - 自动对比实盘当前持仓（如持有的 QQQ、DIA、BOXX）与策略目标持仓，生成高可读性的换仓理由；
4. **双通道交互提醒**：
   - **飞书长连接/Webhook 交互卡片**：盘后秒级推送到手机/电脑；
   - **本地 Web 可视化看板**：支持一键复制纯整数调仓清单并核对风控明细。

## 🚀 快速开始

### 1. 环境准备

推荐使用 Python 3.10 ~ 3.13 虚拟环境：
```bash
pip install -r requirements.txt
```

确保本地已启动并登录 **富途牛牛 / Moomoo OpenD 网关程序**：
- 默认监听地址：`127.0.0.1:11111`
- 开启港美股交易解锁与 API 权限。

### 2. 配置与脱敏引导

1. **策略与服务配置**：
   复制 `config/config.example.json` 为 `config/config.json`，根据需要填入飞书机器人凭证（可选）及交易环境：
   ```bash
   cp config/config.example.json config/config.json
   ```
2. **AI 投决会 Key 配置**：
   复制 `config/apikey.example.txt` 为 `config/apikey.txt`，填入您的 DeepSeek API Key：
   ```bash
   cp config/apikey.example.txt config/apikey.txt
   # 将里面的内容替换为例如: sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   > 💡 注：`config/config.json` 与 `config/apikey.txt` 均已被 `.gitignore` 严格忽略，绝不会被 Git 提交泄露。

### 3. 一键启动 Web 看板与后台服务

- **Windows 用户**：直接双击 `start.bat` 即可一键启动后台服务并自动在浏览器打开看板：
  👉 访问地址：**`http://127.0.0.1:5000`**
- **停止服务**：双击 `stop.bat` 即可安全释放所有端口与后台进程。

### 4. 运行自动化测试套件

运行完整测试用例，验证系统无回溯漏洞且安全锁生效：
```bash
pytest -v
```

### 5. 执行全周期高保真回测

运行 2016-2026 全周期回测，生成净值曲线与对比数据：
```bash
python src/run_coresatellite_backtest.py
```
