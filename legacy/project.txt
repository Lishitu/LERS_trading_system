# Leveraged ETF Regime Switching System (LERS)

## Project Objective

Build a quantitative trading system that dynamically allocates capital among leveraged ETFs based on market regime prediction.

The goal is not stock selection.

The goal is to identify:

* Risk-On
* Risk-Off
* Neutral

market states and switch between:

* TQQQ
* SQQQ
* Cash

to outperform Buy & Hold TQQQ on a risk-adjusted basis.

---

# Phase 4: Label Generation

Create market state labels using future 5-day returns.

future_ret_5d = close.shift(-5)/close - 1

Labeling rule:

If future_ret_5d > 2%:
RiskOn

If future_ret_5d < -2%:
RiskOff

Else:
Neutral

Encoding:

RiskOff = 0

Neutral = 1

RiskOn = 2

# Phase 6: Portfolio Engine

## Trading Actions

Possible positions:

1. TQQQ

2. SQQQ

3. Cash

Only one position at a time.

---

## Decision Rule

If P(RiskOn) > 0.60:

```
Hold TQQQ
```

Else if P(RiskOff) > 0.60:

```
Hold SQQQ
```

Else:

```
Hold Cash
```

---

## Execution

Signals generated at close.

Trades executed at next market open.

Avoid look-ahead bias.

---

# Phase 7: Walk Forward Testing

Do NOT use random train/test splits.

Implement rolling walk-forward validation.

Example:

Train:
2011-2018

Test:
2019

Then:

Train:
2011-2019

Test:
2020

Continue until present.

Combine all out-of-sample results.

# Success Criteria

The strategy should satisfy:

1. Sharpe Ratio > Buy & Hold TQQQ

2. Maximum Drawdown significantly lower than Buy & Hold TQQQ

3. Positive out-of-sample CAGR

4. Consistent walk-forward performance

5. Robust results across multiple market regimes
